# 📚 Agentic AI Research Assistant

An AI-powered research assistant using Hugging Face Transformers and Gradio.

## 🚀 Features

- Topic Research
- AI Summary
- Study Notes
- Quiz Generation
- Key Insights
- Multi-Agent Workflow

---

## 🛠 Tech Stack

- Python
- Gradio
- Hugging Face Transformers
- Wikipedia API

---

## ⚡ Installation

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Project

```bash
python app.py
```
